# Estudio Puerto Varas · Informe

Informe visual: matrícula, establecimientos y migración estudiantil en Puerto Varas, Puerto Montt, Frutillar y Osorno (2015-2025).

Ver en vivo: https://brojasgonzalo.github.io/estudio-puerto-varas-informe/
